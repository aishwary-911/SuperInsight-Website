Classic Version (v3.3) Flagship Standalone

SuperInsight Classic Version (v3.3)

The comprehensive flagship desktop analytics suite. Features full Data Model Training (AutoML, Classification & Regression) and Image Model Training (Computer Vision), bundled with automated data cleaning, integrated Python REPL editor, and conversational Google Gemini AI assistant.

Confirmed Features of Classic v3.3:

  • Self-Contained Bundle: Embedded Python runtime with all machine learning and computer vision libraries pre-configured.
  • Data Model Training (Tabular ML): Automated machine learning (AutoML), Random Forest, Gradient Boosting, XGBoost, Regression models, and hyperparameter grid tuning.
  • Image Model Training & Vision: OpenCV image preprocessing, visual filters, feature extraction, and image classification model training.
  • Advanced Data Preprocessing: Mean, Median, Mode, KNN Imputation, Iterative MICE, Outlier detection & trimming, MinMax/Standard scaling, and One-Hot encoding.
  • Integrated Python REPL Editor: Direct programmatic interaction with active dataframes for custom scripting and mathematical transformations.
  • SuperInsight AI Assistant: Plain-English dataset questions answered via Google Gemini with multi-turn session context.
  • In-Memory Privacy Guarantee: Zero persistent server database; all computations execute locally in workstation RAM.

SuperInsight Lite Version (v1.0)

System Architecture & Profile

Technical Specifications

In-depth technical architecture describing computational requirements, runtime memory footprints, packaging standards, and execution security for SuperInsight.

Packaging & Deployment

Self-contained executable setup packages engineered for single-click Windows installation with all core analytical runtime components bundled.

  • Classic Target: Full Vision & ML (.exe)
  • Lite Target: Tabular ML (.exe)
  • Packaging Format: Self-Contained

CPU Architecture

Requires a 64-bit multi-core processor (x86_64). Automated data cleaning, parallel grid search, and scikit-learn model fitting take advantage of all CPU cores.

  • Architecture: 64-bit (x86_64)
  • Classic Target: Intel i3/i5/i7, AMD Ryzen
  • Lite Target: Intel i3/i5, AMD Ryzen

RAM Requirements

SuperInsight operates strictly in-memory. System memory determines the maximum dataset row count and tabular feature matrix dimensions handled without paging.

  • Classic Min / Rec: 8 GB / 16 GB
  • Lite Min / Rec: 4 GB / 8 GB
  • Memory Architecture: 100% In-Memory

GPU Acceleration Support

Neither edition requires a discrete GPU to operate. CPU-based training is standard, with optional NVIDIA CUDA hardware acceleration in Classic for image processing.

  • Classic GPU: Optional (CUDA Acceleration)
  • Lite GPU: 100% CPU Optimized
  • Hardware Baseline: No Dedicated GPU Required

Security & Data Privacy

Operates completely client-side in workstation memory. No dataset records, trained model weights, or user code are transmitted to external servers.

  • Data Boundary: 100% Local Workstation
  • Cloud Storage: Zero Cloud Persistence
  • Telemetry: Zero Tracking / Private

Operating Systems

Officially packaged, compiled, and verified exclusively for 64-bit Microsoft Windows workstations, laptops, and virtual environments.

  • Windows 11 (64-bit): ✓ Supported
  • Windows 10 (64-bit): ✓ Supported
  • Binary Architecture: x86_64 Native
